# WaCSim User Manual (NewDocs)

This folder contains the new user manual for WaCSim, organized as follows:

- **Part A** – Quick Start: installation and running your first example
- **Part B** – Concepts & deep dive (control modes, attacks, events, custom algorithms, output)
- **Part C** – Tutorials (task-based)
- **Part D** – Reference (config options)
- **Part E** – Installation (detailed)
- **Part F** – Examples index

All content is in reStructuredText (`.rst`) so it can be built with Sphinx or read as plain text.
