========================================
WaCSim User Manual
========================================

This manual helps you install, understand, and use WaCSim (Water and Cyber Simulation) — a cyber–physical digital twin for water distribution systems.

**Recommended order:**

1. **Part A: Quick Start** — Install WaCSim and run your first example.
2. **Part B: Concepts** — Deep dive into how WaCSim works (control modes, attacks, events, custom algorithms, output).
3. **Part C: Tutorials** — Task-based: add an attack, add a custom algorithm, etc.
4. **Part D: Reference** — Full config options (experiment, attacks, events, custom algorithms).
5. **Part E: Installation** — Detailed install (e.g. VM, Ubuntu, dependencies).
6. **Part F: Examples index** — Where to find example configs and what each demonstrates.
